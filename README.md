# 🏆 合宿レク イベント進行＆得点管理ツール

社員旅行（合宿）のレクリエーション用に作った、**PC＋モニター投影対応**の進行ツールです。
管理者が得点を操作すると、投影画面にリアルタイムで反映されます。景品ガチャや演出も搭載。

デザインは **Apple Japan（apple.com/jp）のデザイン仕様**（awesome-design-md-jp / apple DESIGN.md）に準拠：SF Pro JP系フォントスタック、`#1d1d1f`テキスト、ピル型ボタン、すりガラスナビ、黒ヒーローの投影ステージ。クイズ「フジヌマ男爵からの挑戦状」のみ元スライドの宝の地図デザインを維持しています。

- **5チーム / 23名** の構成・お題・配点は [進行表PDF] の内容をそのまま初期値に設定済み
- **インストール不要**：`index.html` をダブルクリックしてブラウザで開くだけ
- **オフライン動作**：インターネット接続不要。データはブラウザに自動保存されます
- 効果音・紙吹雪・演出はすべて内蔵（外部ファイル・通信なし）

## 🚀 使い方（当日の流れ）

### 1. 起動
`index.html` をダブルクリック（推奨ブラウザ：Google Chrome / Microsoft Edge）。

### 2. 投影のしかた

**基本の手順（いちばん確実・claude.ai版でもローカル版でも動作）：**
1. 同じページを**もう1つのタブ（別ウィンドウ）**で開く
2. そのタブで右上の **「📺 投影モード」** を押す（操作パネルが消え、投影内容だけの全画面表示に）
3. そのウィンドウをモニター側へ移して全画面に。手元のタブの操作がリアルタイムで反映されます
4. 投影側を戻すときは **Esc キー**（または左上のボタン）

補助手段：
- **⛶ 全画面** … モニターに**ミラーリング**（複製表示）する場合はこれだけでOK
- **🖥 投影ウィンドウ** … ローカルの `index.html` なら別窓が自動で開きます（claude.ai版はポップアップ制限で開けないため上記手順を使用）
- **投影用URL（#present）** … ダウンロード版 `index.html` では、URL末尾に `#present` を付けて開くと最初から投影モードで起動します

> ⚠️ **同期は同一ブラウザ内のみ**。別デバイス（スマホ等）で開いた画面とは同期しません。当日の本番は、ダウンロードした `index.html` を同じPCの2ウィンドウで開く構成が最も確実です。

### 3. 進行

画面右側のタブで操作します。

- **🎯 得点** … 各チームへの加点・減点。クイズ／イラストの配点ボタン、**チャレンジ種目ルーレット**、チャレンジゲームの順位一括入力、取り消し（Undo）、操作ログ。
- **📜 クイズ**（フジヌマ男爵からの挑戦状）… 全20問（各5点・記述式）を宝の地図テーマで投影。オープニング／問題／エンディングの切替、問題送り・答え表示、シンキングタイム30秒、正解チームへの「正解+5」加点まで一括操作。
- **⏱ タイマー** … シンキングタイム用カウントダウン（30秒・60秒・任意）。スタートすると投影が自動でタイマー表示に切替。残り5秒でカウント音、0秒で演出。
- **🎨 お題** … テーマイラスト当ての正解（全15問）を1問ずつ表示／隠す。操作すると投影も自動で切替。
- **🎁 ガチャ** … 景品ガチャ。当選チームを選んで回すとリール演出＋紙吹雪。景品の追加・残数管理も可能（景品16品＝各1個を登録済み）。
- **📋 進行** … 当日のタイムテーブル・配点ルール。チーム名の編集、**ゲームマスター（主催者）の写真登録**、スコアのリセットもここから。

> 🎪 **ゲームマスター機能**：「📋 進行」タブから主催者（藤沼さん）の写真を登録すると、スコアボード左下と結果発表画面に主催者として表示され、優勝チームへのお祝いコメントも出ます。写真は端末内にのみ保存されます。

> 🎯 **チャレンジ種目ルーレット**：「🎯 得点」タブの「ルーレットを回す」で、5種目（腕相撲・片足立ち・だるまさんが転んだ・10秒ストップ・早飲み対決）からランダムに種目を決定。投影に回転ルーレットの演出が表示されます。

### 4. 投影シーンの切替
各タブ上部の **シーンボタン**（🏆得点表 / 📜クイズ / 🎯ルーレット / ⏱タイマー / 🎨お題 / 🎁ガチャ / 🎉結果発表）で、投影画面に映す内容を切り替えられます。最後に「🎉結果発表」で表彰台＋ファンファーレ＋紙吹雪の演出。

## 💡 便利機能
- **自動保存**：操作するたびにブラウザ内に保存。誤ってタブを閉じても続きから再開できます。
- **取り消し**：得点タブの「↩ 直前の操作を取り消す」でミスをリカバリ。
- **🔄 イベント前リセット**：「🎯 得点」タブ／「📋 進行」タブの「イベント前リセット」で、テスト中に入れた得点・ガチャ結果（景品残数も全回復）・ルーレット・クイズ／お題の進行位置・タイマーを一括で初期状態に戻せます。チーム名とゲームマスター写真は保持されます。
- **全データ初期化**：「📋 進行」タブから、チーム名・写真も含めた完全初期化も可能。

## 🔧 動作の仕組み（技術メモ）
- 単一の `index.html`（HTML/CSS/JavaScript）で完結。フレームワーク・ビルド不要。
- 状態は `localStorage` に保存し、`BroadcastChannel` で管理ウィンドウ↔投影ウィンドウをリアルタイム同期。
- 効果音は Web Audio API で生成、紙吹雪は Canvas 描画。**外部への通信は一切ありません。**
